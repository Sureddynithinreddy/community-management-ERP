# community-management-ERP

Comprehensive Gated Community ERP & Portal Suite built with Vite, React, TypeScript, and Tailwind CSS v3.

## Features
- **Admin Committee Portal (15 Pages)**: Comprehensive analytics, security guard roster, master resident directory (250 flats), financial reports, visitor management, incident console, emergency sirens, amenity approvals, maintenance schedules, notice publisher, billing engine, audit trail, community config, and staff/vendor credentials management.
- **Resident Portal (6 Pages)**: Spending telemetry, maintenance bill payments with tax invoice download, visitor push approvals + pre-approved guest pass generator (QR code & OTP), helpdesk complaints with SLA timers and rating controls, sports court & banquet hall booking, and community announcements with active polls.
- **Security Gate Portal (10 Pages)**: Gate terminal telemetry with offline SQLite queue simulation, visitor check-in/out register, delivery shelf storage queue, ANPR license plate scanner lookup & parking violations log, resident verification, real-time panic SOS alert receiver, incident reporting, QR patrol scanner checkpoints, and lost & found register.
- **Mobile Responsive**: Fully responsive layout with custom mobile hamburger drawer navigation.

## Setup & Deployment
```bash
npm install
npm run dev
npm run build
```
